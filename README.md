# 🐾 Site-Pet

Um site responsivo para apresentação e gerenciamento básico de pets.  
Este projeto foi desenvolvido como um **site estático com HTML, CSS e JavaScript**, com páginas como **index** e **login**, além de pastas para **estilos**, **scripts** e **imagens**.

---

## ✨ Visão Geral

O *Site-Pet* apresenta:

✔️ Interface principal de visualização de pets  
✔️ Página de login para autenticação  
✔️ Layout responsivo com CSS customizado  
✔️ Estrutura organizada de arquivos  
⠀  
📁 Estrutura do projeto:

├── asset/
│ └── img/ # Imagens e assets gráficos
├── css/
│ └── *.css # Estilos do site
├── js/
│ └── *.js # Scripts JavaScript
├── index.html # Página principal
├── login.html # Página de Login
└── README.md # Documentação do projeto


Os arquivos HTML foram escritos em **HTML5 padrão**, com estilos em CSS e comportamento mínimo em JavaScript.
